# Developer Portfolio 🚀

A clean, modern, and fully responsive personal portfolio website built with HTML5 and CSS3.

## ✨ Features
- **Responsive Design:** Adapts smoothly across mobile, tablet, and desktop screens.
- **Smooth Navigation:** In-page anchor links for seamless section switching.
- **Modern UI:** Styled with a sleek dark theme and Font Awesome icons.
- **Connect Sections:** Direct links to GitHub and LinkedIn profiles.

## 🛠️ Technologies Used
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, Grid, Custom Properties)
- **Font Awesome** (Icons library)
